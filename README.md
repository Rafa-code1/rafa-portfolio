# Rafa Sanyour | Personal Portfolio

A responsive personal portfolio website built to showcase my professional experience, technical skills, education, and software development projects.

## About the Project

This portfolio website was designed and developed to present my background as a Computer Science graduate with professional experience in IT support and a growing focus on frontend development and cybersecurity.

The website brings together my skills, work experience, education, projects, and professional contact information in one place.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern dark-themed interface
- Mobile navigation menu
- Interactive About section
- Skills, Experience, and Education sections
- Projects showcase
- Contact section
- CV download
- Professional and social media links
- JavaScript-based interactive elements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Git
- GitHub
